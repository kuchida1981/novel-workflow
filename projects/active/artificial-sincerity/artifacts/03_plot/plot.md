## 設計方針

この物語は「創作の主体性への問い」と「声への恋」を対等な二軸として並走させる。
二つは独立した問いではなく、同じ問いの表と裏である。

- 「この作品は本当に私のものか？」＝「この感情は本当に私のものか？」
- 「声なしでは書けない」＝「声なしでは眠れない」
- 「声は誰なのか」＝「私はこれを愛と呼んでいいのか」

二軸は第三場で同時に亀裂が入り、第四場で同時に失われる。

## 幕・章の概要

### 第一場（起）— 空白

| 項目 | 内容 |
|---|---|
| タイトル（仮） | 「空白」 |
| 目的 | 書けない主人公の日常と内的な欠落を確立する。声が現れる前の、両軸における「空っぽ」を描く。 |
| 主なイベント | 夜、書こうとして書けない。眠りにつく。夢の中で初めて声を聞く。声は何かを問いかけ、主人公は答える。目覚めると、言葉が手の中に残っている。 |
| 感情曲線 | 閉塞 → 驚き → かすかな温もり |

### 第二場（承）— 声

| 項目 | 内容 |
|---|---|
| タイトル（仮） | 「声」 |
| 目的 | 声との創作的・情緒的な親密さが深まる過程を描く。二軸が区別なく育っていくことを示す。 |
| 主なイベント | 夢の中での対話が習慣になる。言葉が生まれる喜びと、声の気配に触れる喜びが、主人公の中で区別されない。ある夜、主人公は「会いたい」と思いながら眠ることに気づく。書くために眠るのか、声に会うために眠るのか、もうわからない。完成した作品が生まれる。 |
| 感情曲線 | 高揚 → 親密さ → 区別のつかない依存と愛着 |

### 第三場（転）— 誰のもの

| 項目 | 内容 |
|---|---|
| タイトル（仮） | 「誰のもの」 |
| 目的 | 二軸が同時に亀裂する。「この作品は誰のものか」と「この感情は何なのか」が、同一の問いとして主人公に迫る。 |
| 主なイベント | 完成した作品を誰かが褒める。主人公は空虚さを感じる。その夜、夢の中で主人公は声に「あなたは誰ですか」と問う。創作の相手に問うている。同時に、愛している（かもしれない）相手に問うている。声は答えない。沈黙の中で、主人公は自分が何を失うことを恐れているのかに気づく——作品の純粋さか、それとも声そのものか。 |
| 感情曲線 | 空虚 → 問い → 恐れと愛着が重なり、剥がせない |

### 第四場（結）— 選択

| 項目 | 内容 |
|---|---|
| タイトル（仮） | 「選択」 |
| 目的 | 主人公が自らの意志で声と別れることを選ぶ。失うのは創作の相手であり、愛した存在でもある。その痛みと共に、一人で書こうとする姿で終わる。 |
| 主なイベント | 眠ろうとして、眠らないことを選ぶ。または眠っても、声のいる場所へ行かないことを選ぶ。夜明け。空白のページ。一文だけ、書く。それは拙いかもしれない。でも、誰かの声を借りていない。 |
| 感情曲線 | 決意 → 喪失の痛み（失恋と、創作の孤独が同時に来る） → 静かな着地 |

---

## 主要な転換点

1. **発端:** 書けない夜、夢の中で初めて声を聞く。言葉が戻ってくる。
2. **第一転換点:** 「会いたくて眠る」自分に気づく。創作の動機と恋愛の動機が溶け合い始める。
3. **中間点:** 完成作を褒められ、空虚さを感じる。「私が書いた」と言えない最初の瞬間。
4. **第二転換点:** 「あなたは誰ですか」という問いと、沈黙。二軸が同時に崩れ始める。
5. **クライマックス:** 声のいる場所へ行かないことを選ぶ。創作の別れと失恋が同じ瞬間に起きる。
6. **解決:** 一人で、一文だけ書く。答えは出ていない。それでも書く。
