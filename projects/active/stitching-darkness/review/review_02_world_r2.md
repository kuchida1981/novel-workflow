## 3. 提案：逆進的インフラ負担について

### アイデアの評価

**採用を強く推奨する。**

「AIを使わない層もAIインフラのコストを逆進的に負担する」という構造は、この世界に以下の三つを加える。

**① 搾取の不可視性**  
アナログ残留層は「AIの恩恵を受けていない」のではなく、「AIの恩恵を受けながら、その費用を不均衡に払わされている」。強者層はこの構造に気づいていないか、気づかないふりをしている——これは悪意よりも無関心という形の搾取であり、ブラックユーモアとして機能する。

**② 世界ルールの自己強化**  
残留層は「AI課金ができないから貧しい」のではなく、「インフラコストを取られるから課金への移行資金が溜まらない」という罠に置かれる。抜け出せない構造的理由が生まれる。

**③ テーマとの直結**  
「真正性」に金を払う強者が、その真正性を作り出している残留層のインフラコストをさらに増大させているという二重搾取の図式は、core のテーマ（歪な価値観）を経済的に具体化する。

---

### 具体的な現れ方（案）

以下のいずれか、あるいは複数を世界ルールに追加することを提案する。

| 現れ方 | 説明 |
|---|---|
| **電力の逆流負担** | 大規模データセンターの電力需要が基本料金・従量料金を押し上げ、AI非使用者も高騰した電気代を払う |
| **人的サービスの消滅と代替コスト** | AIに置き換えられた窓口・医療・教育が消滅し、「生身の人間に会う」こと自体が高コスト化。残留層はその代替コストを自力で負担する |
| **AI最適化価格差別** | 企業がAIで購買データを解析し、AI非活用の消費者から「最適化されていない高値」を引き出す。残留層は常に定価以上を払わされる |
| **土地・住居の追い出し** | データセンターや技術拠点の誘致によって、その周辺地価が高騰し、低所得者層が居住地を追われる |

### 世界ルールへの組み込み案（文章イメージ）

```
- **逆進的インフラ負担**:
    AIエコシステムの維持コスト——電力、冷却水、通信インフラ——は
    計算資源を独占する強者層が生み出す需要を源泉としながら、
    その負担は利用量と無関係に全住民へ分配される。
    AI非使用者は、自分が一度も恩恵を受けていない
    サービスの電気代を毎月支払い続けている。
    計算資源強者はこの構造に無頓着であり、
    残留層はそれを指摘する言語すら持てないでいる。
```

## 4. 細部の確認事項

### 「課金プラン」という語について

「学校（進路指導室）」の説明中に「課金プラン」という現代のサービス用語が登場している。「ティーン」と同様に、設計語が本文に漏れている可能性がある。物語世界の語彙（「演算契約」「資源等級」「AIグレード選別」など）への置換を検討する。

### プロンプト・スラムの命名

場所名として機能するが、「プロンプト」という技術用語が物語内の固有名詞として定着しているかどうかを、後のステップ（キャラクター・セリフ設計）で整合させる必要がある。固有名詞として使うと決めたなら、他の場所名にも同様の語彙水準を揃えるとよい。
