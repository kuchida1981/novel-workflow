# Step 4: シーン (Scenes)

> **依存:** `03_plot/plot.md` (approved)

## 設計不変量 (Design Invariants)

執筆（Draft）ステップにおいて、以下の設定と語彙を厳守すること。

- **エレンの立場**: 独立した偽造職人。工房の一角を賃借しており、インフラ負担金（電気代）の変動が直接彼女の利益を削る。
- **語彙体系**:
    - **算力（さんりょく）**: 演算資源の正式・技術的呼称。
    - **枠（わく）**: 個人が利用できるAIの許容量。
    - **学費**: リアムの文脈では「教育用AIの演算契約料」と同義。
- **固有名詞**:
    - **真正院（しんせいいん）**: ハドソンの経営するサロン。真正性を崇拝する宗教的な場。
- **禁則**: 地の文において「強者層」「サブスク」「課金」などの設計語を直接使用しない。代わりに感覚的な描写（例：「光の側」「契約の維持」「重い負担」）に置き換える。
