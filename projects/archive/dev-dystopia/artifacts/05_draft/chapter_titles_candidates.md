# 章タイトル候補

## 第1章
**物語の核**: 資源（雫）が枯渇した没落貴族のもとに招待状が届き、リネットが「五滴の雫」だけで舞踏会を成功させる。献身と職人的演算の章。

| 候補 | 意図・ニュアンス |
|------|----------------|
| 五滴の奇跡 | 最少の資本で最大の輝きを生む、職人技の出発点を端的に示す |
| 銀の針と星の雫 | リネットの技と唯一の資源を並置。世界観の導入として機能 |
| 枯れた噴水の誓い | 1-1の冒頭イメージと、リネットの決意を結ぶ |
| 十四分の輝きへ | 1-3のラストから逆算した緊迫感と、刹那の美しさ |
| 光らない星の子ら | 雫を持てぬ者たちの現実と、そこから這い上がろうとする意志 |

### 銀の針と星の雫  

を採用


## 第2章
**物語の核**: 自動織機アリアドネの出現。リネット自身の知恵が機械に飲み込まれているのを発見する衝撃と、「職人の意地」で一滴への挑戦を誓う章。

| 候補 | 意図・ニュアンス |
|------|----------------|
| 黄金の鉄針 | アリアドネの象徴を凝縮。「黄金」＝資本、「鉄針」＝機械的効率の二重性 |
| 知恵を呑む機械 | リネットの技法がデータとして搾取される恐怖を直截に表現 |
| 私が、考えた | 2-1の核心台詞から。己の創造物を奪われた怒りと戸惑い |
| 職人の一滴 | 2-3の終着点。機械への対抗手段としての「人間性」の凝縮 |
| 平均値の戦場 | 機械は「平均」しか生めないという反論が軸。抽象的だが主題的 |

### 黄金の鉄針 

を採用

## 第3章
**物語の核**: 一滴の雫でドレスが輝く「歓喜の勝利」と、その効率化が直接の原因でマーサたちお針子が解雇される「喪失」が表裏一体になる章。

| 候補 | 意図・ニュアンス |
|------|----------------|
| 歓喜の収支 | 3-1の原題を活かす。会計用語「収支」が勝利と損失の両面を冷徹に映す |
| 一滴と十人の影 | 雫「一滴」の節約が「十人」の解雇を生む構造を数字で対比 |
| 消えていく背中 | 3-3のラスト、去っていくマーサたちの後ろ姿から |
| 正解の代償 | 「正解」を出した瞬間に他者の価値が「高いコスト」に変わるという残酷さ |
| 勝利の亀裂 | 外側は勝利だが、その内側で静かに何かが割れていく感覚 |

### 消えていく背中 

を採用

## 第4章
**物語の核**: リネットがアリアドネへ「リネット縫い」の全知識を入力し、自分自身を機械に移植する。そして男爵に銀の針を取り上げられ「管理職」に配置換えされる章。

| 候補 | 意図・ニュアンス |
|------|----------------|
| 針を置く日 | 4-3の原題を活かす。静かな喪失。主体的に「置く」ように見えて強制された悲劇 |
| 魂を刻む機械 | 4-1「私は今、私を作っている」の感覚を圧縮 |
| 究極のパターン | 4-1の原題から。完璧な「正解」への到達と同時に起こる空洞化 |
| おめでとう、自由人 | 4-3ラストの男爵の台詞を逆説的タイトルに。皮肉が際立つ |
| 完璧な答えの空白 | 理論上の限界に達したとき、リネットの中に残ったものの不在 |

### 針を置く日 

を採用

## 第5章
**物語の核**: 完璧に輝くエルザを暗いバルコニーから見下ろすリネット。そして城を出て、最後の銀の針を樫の木の根元に埋める。解放と別れの章。

| 候補 | 意図・ニュアンス |
|------|----------------|
| 銀の針を土に | 5-3の原題を活かす。最もシンプルかつ重い終幕 |
| 完璧な輝きの彼方 | バルコニーからエルザを見る距離感。「彼方」に疎外と解放の両義 |
| さよならの重さ | 5-3の「さよなら」が誰への言葉か分からない問い。余韻を残す |
| 針の眠る場所 | 銀の針が土の下で眠るという静止画で物語を閉じる |
| 誰も知らない奇跡 | ラスト一文の精神——気づかれることなく土に還った知恵と愛 |
